# Janu V3

বাংলা voice-control ভিত্তিক Android assistant-এর প্রথম পূর্ণ project।

## Build
GitHub-এ এই project upload করে Actions থেকে `Build Janu V3 APK` চালান।

## গুরুত্বপূর্ণ
- প্রথম চালু হলে Microphone/Call/SMS permission চাইতে পারে।
- Back/Home-এর জন্য Android Settings → Accessibility → Janu V3 চালু করতে হবে।
- Voice recognition আপনার ফোনের speech-recognition service-এর উপর নির্ভর করে।
- কিছু system/app action Android-এর নিরাপত্তা সীমাবদ্ধতার কারণে permission বা Accessibility চাইতে পারে।
